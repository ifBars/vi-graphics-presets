# Credits

This project targets the native compatibility work started by [Marvisak/VIctory](https://github.com/Marvisak/VIctory) and continued by community forks, including [fxceless/victory-fork](https://github.com/fxceless/victory-fork) and [ZigZagBoi1/ScarlettPort](https://github.com/ZigZagBoi1/ScarlettPort).

The initial adapter extends ScarlettPort's loader and keeps its GPL-3.0-or-later licensing. The preset planner and Windows plugin were written for this project. Build hashes, offsets, parameter names and short instruction signatures identify the supported local title build; they do not provide the game.

RAGE research tools, SixNG, Capstone and Ghidra were used for local static investigation. The source archives, extracted configuration, saves and private runtime evidence are kept outside this repository.
